# ESP32 AI Control v0.1.0 — Stage 3

Добавлено:
- сохранение MQTT URL и последнего введённого адреса;
- отдельная вкладка/экран устройств;
- карточки устройств;
- страницы виджетов;
- нормальные кнопки toggle;
- отображение online/offline;
- автообновление значений status/event;
- экран MQTT диагностического журнала;
- кнопка HELLO;
- подготовлена архитектура под AI-команды.

Ограничение:
Фактический payload исходящей команды пока не считается окончательно подтверждённым.
Для toggle используется `1`, для input — введённое значение.
